### Resume — a kill is a checkpoint, not a restart

All three CLIs continue a killed or expired session. Resume after any backstop kill or
hang kill where partial progress is real.

| CLI | Resume |
| --- | --- |
| agy | `agy -c` (most recent) or `agy --conversation <id>` |

Working-tree progress survives the kill; run `git diff` before resuming to see what has
already landed.

## agy

### Dispatch

```bash
agy --model gemini-3.6-flash --effort <low|medium|high> \
  --add-dir <repo> --print-timeout 5m -p "<PROMPT>" < /dev/null
```

### Verified behavior

- agy print mode buffers output. Use process existence plus `--print-timeout` as the
  liveness signal and backstop.
- `-p` consumes the next argument as the prompt. A flag after `-p` becomes the prompt,
  and the real task and model selection are silently dropped. Put `-p "<PROMPT>"` last.
- Headless honors persisted `settings.json` policies. File tools run under the default
  policy; shell `command` execution is auto-denied without an allow rule. No enforced
  read-only tier exists.
- Document-shaped tasks write their answer to
  `~/.gemini/antigravity-cli/brain/<conversation-id>/*.md` and print only a banner to
  stdout. Instruct the agent to output its full answer inline and not write a file. If
  stdout is banner-only, sweep for the artifact:

  ```bash
  find ~/.gemini/antigravity-cli/brain -name '*.md' -mmin -10 \
    -not -path '*/.system_generated/*' | xargs ls -t | head -1
  ```

  Use `-mmin`, not `-newermt '-10 minutes'`.
- The artifact tool writes only inside
  `~/.gemini/antigravity-cli/brain/<conversation-id>/`. For a workspace report path,
  direct the agent to use its ordinary workspace file-write tool, not the artifact tool
  or a shell command. This steering is mechanistically targeted but not statistically
  verified; the reliable approach for read-lane dispatches is to capture the full report
  as the final message instead of asking the agent to write a file.
- Bogus models produce a clean error listing available models.
- Display labels such as `"Gemini 3.6 Flash (Low)"` and slugs such as
  `gemini-3.6-flash-low` both work. Use the effort embedded in the name or a base slug
  with `--effort low|medium|high`; combining `--effort` with an effort-suffixed name
  errors.
- One prompt runs per turn in print mode; `--print-timeout` bounds the wait.

## Headless permission baseline

Headless agy reads the persisted permission policy at
`~/.gemini/antigravity-cli/settings.json`. Unconfigured actions default to Ask, which
headless auto-denies with exit 0, zero work, and a banner on stdout. Use an allow/deny
baseline in that file. Rules use `action(target)` syntax, one whitespace-separated
anchored-regex token each; precedence is Deny > Ask > Allow; `command(*)` wildcards a
whole namespace.

```json
"permissions": {
  "allow": [
    "command(uv)", "command(python3)", "command(python)", "command(pytest)",
    "command(git (status|diff|log|show|rev-parse|ls-files|branch))",
    "command(ls)", "command(cat)", "command(echo)", "command(mkdir)", "command(touch)",
    "command(cp)", "command(mv)", "command(sed)", "command(grep)", "command(rg)",
    "command(find)", "command(head)", "command(tail)", "command(wc)", "command(diff)",
    "command(chmod \\+x)", "command(make)", "command(npm (test|run))", "command(node)"
  ],
  "deny": [
    "command(sudo)", "command(rm -rf? /)", "command(git push)", "command(git commit)",
    "command(curl)", "command(wget)", "command(ssh)"
  ]
}
```

- The file is machine-local and user-global; the plugin cannot ship it. Without the
  baseline, a first dispatch on a fresh machine silently no-ops, and only the
  controller's diff-after/report-exists gate catches it.
- Before the first agy dispatch of a session, run
  `grep -q 'permissions' ~/.gemini/antigravity-cli/settings.json`; on a miss, stop and
  provide this baseline.
- The rules also apply to interactive agy sessions. The `git commit` and `git push`
  denies block interactive commits too.
- `--dangerously-skip-permissions` is a zero-setup fallback that auto-approves
  everything and gives up deny-list containment.
- A denied command produces the silent-no-op signature. Add a needed command to the
  allow list and record it here.

## Canonical dispatch template

```bash
agy --model <resolvable-model-id> --add-dir <repo> --print-timeout <t> -p "<PROMPT>" < /dev/null
```

**Effort XOR rule:** resolvable model IDs carry their effort suffix. Use an
effort-suffixed model ID or a base model slug with `--effort <low|medium|high>`, never
both.
